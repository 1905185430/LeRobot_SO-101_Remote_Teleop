<threat_model>
- T3-07: Reliability helpers swallow exceptions and hide failed operations. Mitigation: retry helper returns operation result only on success and re-raises the final exception after recording it.
- T3-08: Retry behavior becomes an implicit state machine. Mitigation: implement one small bounded function with `attempts` and optional no-op sleep.
- T3-09: Diagnostic events miss enough context to debug operator failures. Mitigation: include stage, component, exception type, and message in event details.
</threat_model>
