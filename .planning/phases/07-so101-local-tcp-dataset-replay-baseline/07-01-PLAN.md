# Plan 07-01: Dataset Replay Config And Action Source Foundation

<objective>
Add the config schema and dataset action-source foundation needed to select one local LeRobot SO-101 dataset episode from YAML without connecting to TCP or hardware yet.
</objective>

<must_haves>
- Preserve current SO-101 TCP teleoperation configs and commands.
- Keep `experiment.mode: remote_teleoperation` valid for the bundled replay config so the same YAML can start the existing follower server.
- Implement D-05, D-06, D-07, D-08, D-09, D-10, D-11, and D-12.
- Do not require a real `lerobot` install for unit tests.
- Do not add list parsing or multi-episode YAML support.
</must_haves>

<tasks>

## Task 1: Add Dataset Replay Config Schema

<read_first>
- `lerobot_remote/config/schema.py`
- `lerobot_remote/config/loader.py`
- `tests/test_config_loader.py`
- `.planning/phases/07-so101-local-tcp-dataset-replay-baseline/07-CONTEXT.md`
</read_first>

<action>
Add a frozen `DatasetReplayConfig` dataclass and a `dataset` field to `PlatformConfig`. Parse scalar fields `path`, `episode`, `start_frame`, `end_frame`, `timing`, and `replay_frequency`. Validate that `timing` is `fixed_hz` or `source_timestamps`, numeric values are sane, and missing path can be detected by runtime-facing validation helpers.
</action>

<acceptance_criteria>
- Loading a config with `dataset:` exposes all requested fields through `PlatformConfig.dataset`.
- `PlatformConfig.summary()` includes enough dataset information for dry-run/operator visibility.
- Invalid timing or negative episode/start frame raises `ConfigError`.
- Existing teleop and inference config tests still pass.
</acceptance_criteria>

## Task 2: Add Dataset Action Source Adapter Boundary

<read_first>
- `lerobot_remote/teleop/actions.py`
- `lerobot_remote/teleop/safety.py`
- `tests/test_tcp_teleop.py`
- `07-RESEARCH.md`
</read_first>

<action>
Create `lerobot_remote/replay/dataset.py` with small replay data structures and action sources. Include a fake/in-memory action source for tests and a lazy LeRobot dataset source that resolves the configured local path, selected episode, frame range, action keys, and optional timing metadata. Normalize actions into the same mapping shape expected by TCP teleoperation.
</action>

<acceptance_criteria>
- Fake source can produce ordered SO-101 action frames without hardware or LeRobot.
- Missing local dataset path fails before any network send is possible.
- LeRobot import failure produces an actionable error that tells the operator to install/use LeRobot or run official replay preflight.
- `source_timestamps` reports clear availability/failure instead of silently falling back.
</acceptance_criteria>
