# Structure

## Repository Layout

- `README.md` documents the current minimal async inference workflow.
- `policy_server.py` is the GPU/server-side async inference entrypoint.
- `robot_client.py` is the robot-side async inference entrypoint.
- `legacy/` contains the old custom UDP teleoperation implementation.
- `tests/` contains top-level tests for the current scripts and a compatibility loader for legacy tests.
- `legacy/tests/` contains direct tests for the legacy UDP protocol and runtime behavior.
- `configs/`, `docs/`, `scripts/`, and `so101_async/` are present but contain no source files in the current tree.
- `logs/` contains generated runtime logs.
- `map.png` is present but not referenced by the code.

## Main Files

- `policy_server.py`
  - Constants: `HOST`, `PORT`.
  - Functions: `build_server_config`, `main`, `_load_server_api`.
- `robot_client.py`
  - Constants: network, robot, camera, policy, and action queue settings.
  - Functions: `build_camera_configs`, `build_robot_config`, `build_client_config`, `main`, `_load_client_api`, `_load_so101_follower_config`.

## Legacy Package

- `legacy/__init__.py` marks the package.
- `legacy/protocol.py` contains protocol dataclasses, constants, encode/decode helpers, and action normalization.
- `legacy/leader_sender.py` contains the leader-side sender class, CLI parsing, LeRobot leader construction, and runtime loop.
- `legacy/follower_receiver.py` contains the follower-side receiver class, CLI parsing, LeRobot follower construction, UDP socket binding, and runtime loop.
- `legacy/logging_utils.py` contains shared logger setup.

## Tests

- `tests/test_minimal_async_scripts.py` tests the main async scripts with fake LeRobot modules.
- `tests/test_legacy_demo.py` imports legacy test classes so `python3 -m unittest discover -s tests -v` can run the legacy suite.
- `legacy/tests/test_protocol.py` tests wire encoding, decoding, action normalization, and constants.
- `legacy/tests/test_runtime.py` tests leader sending, follower receiving, packet loss behavior, timeouts, latency logging, clock skew handling, and RTT tracking.

## Generated Or Transitional Files

- `__pycache__/`, `legacy/__pycache__/`, `legacy/tests/__pycache__/`, and `so101_async/__pycache__/` contain generated bytecode.
- The git worktree shows deleted root-level legacy files and untracked `legacy/` equivalents, which indicates a move from flat root scripts into the `legacy` package.
- `logs/` is untracked and should be treated as generated runtime output unless deliberately preserved.

## Naming Conventions

- Current main scripts use simple nouns: `policy_server.py`, `robot_client.py`.
- Legacy modules use role-based names: `leader_sender.py`, `follower_receiver.py`.
- Test files use `test_*.py`.
- Protocol constants use upper snake case.
- Config constants in top-level scripts use upper snake case.

## Import Boundaries

- Top-level tests import `policy_server` and `robot_client` directly.
- `tests/test_legacy_demo.py` imports test classes from `legacy.tests`.
- Legacy implementation uses relative imports inside `legacy/`.
- Main scripts do not import from `legacy/`.

## Empty Directories

- `configs/policy_server/` and `configs/robot_client/` exist but are not used by the current main path.
- `docs/` and `scripts/` exist but are empty.
- `so101_async/` currently has bytecode cache files but no source files.
