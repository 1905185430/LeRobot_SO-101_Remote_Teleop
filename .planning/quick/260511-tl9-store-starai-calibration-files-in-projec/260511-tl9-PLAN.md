# Quick Plan: Store StarAI Calibration Files In Project Directory

Date: 2026-05-11
Status: Complete

## Goal

Keep the local StarAI follower and leader calibration files inside the project directory and make the TCP teleoperation config use them.

## Scope

- Copy the existing official LeRobot calibration JSON files into `calibrations/`.
- Point `configs/local_teleop_starai_tcp.yaml` at those project-local calibration directories.
- Add `teleop.calibration_dir` to the config schema.
- Pass robot and teleop calibration directories through the StarAI LeRobot config builders.
- Cover config parsing and StarAI config construction with tests.

## Verification

- `python3 -m unittest tests.test_config_loader tests.test_starai -v`
- `python3 scripts/run_server.py --config configs/local_teleop_starai_tcp.yaml --dry-run`
