# Quick Plan: Fill SO101 Teleop Calibration IDs In Config

Date: 2026-05-11
Status: Complete

## Goal

Use local SO-101 calibration IDs and project-local calibration files in the remote SO-101 TCP teleoperation config.

## Scope

- Copy local SO-101 follower and leader calibration JSON files into `calibrations/`.
- Update `configs/teleop/remote_so101_tcp.yaml` with matching IDs and calibration directories.
- Pass `calibration_dir` through the SO-101 TCP teleop builder path.
- Add a regression test proving SO-101 leader/follower configs receive project calibration directories.
